# VK Видео: обучающая выборка спортивных трансляций

## Содержимое

- `train.jsonl`, `validation.jsonl`, `test.jsonl`: одна строка на 5-секундный отрезок.
- `frames/<clip_id>/frame_*.jpg`: JPEG-кадры шириной 480 пикселей (обычно 480×270), около 5 кадров/с. Полные видео в архив не входят.
- `statistics.json`: число источников, отрезков, распределение меток и ошибки извлечения.

Собрано 404 видеоисточников и 1086 отрезков. Метки `sport`,
`gender`, `age` созданы Luna по `title`, `description`, `duration` и являются **слабыми
метками**: кадры всей выборки визуально не проверены. `age` означает категорию
соревнования: `under_18` строго до 18 лет, `adult_18_plus` — 18+. Пол означает
категорию соревнования, а не оценку внешности участника.

## Формат строки

`clip_id`, `video_id`, `source_group_id`, `start_s`, `duration_s`, `sport`,
`gender`, `age`, `video_scope`, `title`, `description`, `frames`. Пути в `frames`
относительны к корню распакованного архива. `video_scope` принимает `single_match`
или `multi_match_same_category`. Для нескольких игр одной категории окна из разных
частей записи имеют одну метку и один `source_group_id`.

## Обучение

```python
import json
from pathlib import Path

root = Path("/path/to/unpacked_bundle")
rows = [json.loads(line) for line in (root / "train.jsonl").open(encoding="utf-8")]
item = rows[0]
frame_paths = [root / path for path in item["frames"]]
text = (item["title"] or "") + " [SEP] " + (item["description"] or "")
target = (item["sport"], item["gender"], item["age"])
```

Для X3D-S используйте 13 последовательных кадров из одного отрезка. Для DINOv2-S
и EfficientNet выбирайте 4–8 кадров из того же отрезка и агрегируйте их предсказания.
Текстовая ветка получает `title` и `description`. Не подавайте поисковые запросы
или ответы Luna: их в архиве нет. Начинайте с трёх отдельных выходных голов
(`sport`, `gender`, `age`); комбинированные 24 класса сильно несбалансированы.

Разделение выполнено по `source_group_id`. Все отрезки одного видео и видео с
одинаковым нормализованным названием лежат в одной части. При оценке сначала
агрегируйте прогнозы отрезков до уровня видео/группы, затем считайте метрики.
Случайное разделение строк создаст утечку. Проверяйте метрики по каждой категории,
особенно редким молодёжным классам; распределение см. в `statistics.json`.

Кадры извлечены равномерно из разных частей исходной записи. В отдельном окне
может оказаться пауза, заставка или чужая игра; это ограничение слабой разметки.
Для итоговой оценки качества потребуется визуальная проверка тестового поднабора.
