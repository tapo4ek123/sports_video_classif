# Сохранённые результаты

Здесь лежат оригинальные небольшие артефакты ранее проведённых запусков. JSON с конфигурациями, историями, метриками и прогнозами перенесены без изменения численных результатов; изображения иллюстрируют уже разобранные ошибки.

| Каталоги | Этап |
|---|---|
| `E0_*` | SigLIP zero-shot, основной опыт и короткий probe |
| `E1_*`–`E5_*` | UCF101, включая дополнительные B4/ViT и чувствительность batch |
| `A1_*`–`A5_*` | Короткие адаптации MultiSports и смешанной выборки |
| `external_*` | Внешние оценки на MultiSports, MUVY и собранных открытых источниках |
| `vk_probe_*` | Технические короткие прогоны перед основными обучениями |
| `vk_*` без `owner` | Обучения на исходном разделении переданного архива |
| `vk_owner_*` | Дополнительное сравнение с каналами, не встречавшимися в обучении |
| `vk_casebook/`, `vk_quality_speed.png` | Качественный разбор и график качества/скорости |

Для CSV-манифестов используются `metrics.json` и `predictions.json`. Для финального архива — `test_metrics.json`, `validation_metrics.json` и `group_predictions.json`. Последние метрики считают группу один раз после усреднения логитов её окон. `history.json` отражает эпохи; checkpoint выбирался по validation. В `config.json` сохранены seed, параметры, версии и контрольные суммы, которые реально фиксировал соответствующий скрипт.

`benchmark.json` раннего UCF101 включает декодирование видео. Финальный benchmark читает готовые JPEG; CPU-замеры лежат отдельно в `benchmark_cpu.json`. Эти времена нельзя сравнивать как полностью одинаковый процесс.

Все численные таблицы можно посмотреть без весов. Полные обученные checkpoint в Git не включены. В локальной папке для демо перенесены только DINOv2 1f/4f; остальные checkpoint сохранены в исходной рабочей папке проекта. Повторное обучение в те же `--output` каталоги перезапишет прежние результаты, поэтому перед запуском сохранить копию или выбрать новый выходной каталог.
