# Демонстрация DINOv2

Это существующее демо проекта, перенесённое в отдельный репозиторий. Оно использует `vk_owner_dinov2_4f` и те же шесть выбранных групп: три удачных примера и три случая с ошибкой. Основной кандидат отчёта — 1f; для наглядного показа здесь сохранён исходный вариант 4f.

## Запуск

Установить окружение из корня репозитория:

```bash
python -m pip install -r requirements-notebooks.txt
jupyter lab demo/VK_DINOV2_DEMO.ipynb
```

Выполнить ячейки сверху вниз. Модель загружается один раз; прогноз пересчитывается на 17 окнах шести видео. Для показа MP4 из JPEG используется `ffmpeg`. Если полного `sports_training_bundle/frames/` нет, ноутбук автоматически использует включённые кадры `demo/sample_bundle/frames/`. Это мини-набор для демо: обучать или оценивать качество на нём нельзя.

Видеоплеер показывает первое окно каждой группы; изображения ниже — все четыре входных кадра каждого окна. Итоговый прогноз усредняет логиты всех окон группы. Видео собрано из сохранённых JPEG без звука. Заголовок поясняет разметку и не передаётся в классификатор. Выбранные удачи и ошибки не являются случайной выборкой и не дают отдельной метрики качества.

## Локальные веса

В подготовленной папке эти файлы уже находятся на своих местах и исключены из Git:

```text
data/models/dinov2-small/config.json
data/models/dinov2-small/preprocessor_config.json
data/models/dinov2-small/model.safetensors
outputs/vk_owner_dinov2_4f/checkpoint.pt
outputs/vk_owner_dinov2_1f/checkpoint.pt
```

После клонирования кода предобученные DINOv2 можно получить существующим загрузчиком:

```bash
python scripts/download_models.py dinov2
```

Обученные `checkpoint.pt` нужно отдельно перенести из исходной рабочей папки проекта в указанные каталоги, либо повторить соответствующее обучение по `docs/REPRODUCE_MAIN.md` на полном архиве. Сохранённые `config.json` и метрики уже есть в репозитории; pretrained-модель не заменяет обученные головы. `config.json` фиксирует SHA256 использованных весов и разбиения.

## CLI-инференс

Существующий короткий ролик Wikimedia U17 включён в `demo/videos/`. Для показа основного варианта 1f:

```bash
PYTHONPATH=src python scripts/predict_vk_video.py \
  demo/videos/nafta_bistrica_u17_60s_5s.mp4 \
  --checkpoint-dir outputs/vk_owner_dinov2_1f
```

Ранее полученный smoke-результат сохранён в `outputs/vk_inference_smoke.json`. Повтор команды нужен только для проверки работоспособности интерфейса. План показа: [DEMO_GUIDE.md](DEMO_GUIDE.md).
