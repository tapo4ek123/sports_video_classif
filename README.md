# Классификация спортивных видео

По кадрам спортивной записи модель предсказывает **вид спорта**, **мужскую или женскую категорию соревнования** и **возрастную категорию до 18 / от 18 лет**. Финальный набор содержит шесть видов спорта: баскетбол, футбол, гандбол, настольный теннис, большой теннис и волейбол.

Репозиторий показывает выполненный путь исследования: пилот UCF101, проверку переноса, разведку данных, обучение трёх голов и сравнение на новых публикующих каналах. Исследовательские ноутбуки оформлены после экспериментов по сохранённым результатам; обучение осталось в самостоятельных скриптах. Новых моделей или экспериментов при подготовке репозитория не добавлялось.

## Структура

```text
notebooks/                 исследование по шагам, таблицы и графики из сохранённых запусков
scripts/                   исходные CLI-скрипты сбора, подготовки, обучения и оценки
src/sports_video/          общие модели, загрузчики, метрики и фиксация происхождения данных
configs/                   SigLIP prompts и индекс 36 сохранённых конфигураций запусков
data/metadata/             манифесты, каталоги источников и ручные исправления
data/splits/               зафиксированные разбиения UCF101, адаптаций и финального набора
sports_training_bundle/    исходные метаданные архива; полный frames/ нужен для обучения
outputs/                   сохранённые конфигурации, истории, метрики, прогнозы и иллюстрации
demo/                      демо, кадры шести выбранных видео и пример MP4
```

Скрипты сохранены в одном каталоге, чтобы работали их существующие импорты и команды. Их назначение сгруппировано в [карте скриптов](docs/SCRIPTS.md).

Открывать ноутбуки в следующем порядке. Первые шесть читают результаты и метаданные, не запускают загрузку, модели или обучение; для них не нужны GPU и полные видеоданные.

| [02 — перенос](notebooks/02_external_transfer.ipynb) | Проверки MultiSports/MUVY и уже выполненные адаптации |

## Установка и среда

Обучения и замеры выполнены в Python 3.10 / WSL на NVIDIA RTX 3050 Laptop и AMD Ryzen 5 5600U. В CPU-benchmark использовались четыре потока. Проверенные версии: PyTorch 2.6.0, torchvision 0.21.0, Transformers 4.48.3; полный список — [requirements-verified.txt](requirements-verified.txt). Требования к VRAM зависят от модели и batch; результаты памяти сохранены в benchmark и test JSON.

Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-notebooks.txt
export PYTHONPATH=src
jupyter lab
```

Для CUDA нужна сборка PyTorch/torchvision, совместимая с драйвером. Для воспроизведения только CLI достаточно `requirements.txt`. Для сборщиков с `yt-dlp` дополнительно нужен `requirements-acquisition.txt`; они не используются при просмотре результатов. `ffmpeg` нужен для воспроизведения демо и извлечения клипов. На Ubuntu/WSL: `sudo apt install ffmpeg`; некоторые архивные сборщики также используют `unzip`. Это внешние системные зависимости, которые не входят в pip requirements.

## Результат и ограничения

На тесте из 61 группы и 165 окон от 23 ранее не встречавшихся публикующих аккаунтов DINOv2-S 1f дала Macro-F1 **0,884 / 0,670 / 0,769** для спорта / пола / возраста и **0,525** по совпадению всех трёх меток. DINOv2 4f лучше по спорту; ResNet-18 быстрее. Итоговый X3D использует вариант `shortside182`

Метки получены gpt-6-luna из заголовков, описаний и длительности; массовой визуальной проверки не было. Исправлено десять видео по виду спорта. Поэтому метрики показывают согласие со слабой разметкой. Категория соревнования не равна оценке пола или возраста человека по внешности. Группа объединяет окна одной записи и видео с одинаковым нормализованным названием; публикующий аккаунт может размещать несколько таких групп.

## Обучение и оценка

Все команды запускаются из корня. Для обучения на переданном архиве нужно дополнить `sports_training_bundle/` полным каталогом `frames/`; одних включённых в Git метаданных недостаточно. Архив содержит 404 видеоисточника, 1086 окон и 26 015 кадров. Полные MP4 в нём не хранятся. Массовый сбор и разметку архива выполнил пользователь; код внешнего сборщика не был предоставлен. В репозитории есть исходные каталоги и сборщики ранней разведки, описание переданного архива и код дальнейшего ML-пайплайна.

Пример уже выполненного основного обучения:

```bash
PYTHONPATH=src python scripts/train_vk_bundle.py \
  --model dinov2_small --weights data/models/dinov2-small \
  --split-dir data/splits/vk_owner_holdout --freeze --frames 1 \
  --epochs 8 --batch-size 16 --lr 0.001 \
  --output outputs/vk_owner_dinov2_1f
```

Сохраняются checkpoint лучшей эпохи по validation, конфигурация, история, метрики и прогнозы тестовых групп. По одному окну 1f использует один центральный кадр. Ответ для исходной записи получается усреднением логитов её окон. Для 4f усредняются признаки четырёх кадров внутри окна, затем логиты окон.

[Воспроизведение основного опыта](docs/REPRODUCE_MAIN.md) содержит подготовку данных, модели, benchmark и инференс. [Воспроизведение пилота](docs/REPRODUCE_PILOT.md) описывает UCF101, SigLIP, адаптации и внешние оценки. [Команды всех сохранённых обучений](docs/EXPERIMENT_COMMANDS.md) восстановлены из фактических `config.json`, включая UCF101, адаптации и probe. Команды используют исторические имена каталогов результатов: перед повторением сохраните копию `outputs/` или измените `--output`, чтобы не перезаписать доказательства прежних запусков.
